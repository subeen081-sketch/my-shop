### 검토 방식

- Figma에 붙여 넣은 **캡처 이미지만 보고** 분석했습니다. 원본 사이트에 들어가 확인한 것은 아닙니다.
- 캡처 해상도가 낮아서 **글꼴 이름, 색상값, 간격 수치는 확인하지 못했고 확정하지 않았습니다.** 크기와 여백은 화면 안에서의 상대적인 관계로만 적었습니다.
- 문구, 로고, 고유 이미지는 옮기지 않고 **구성과 표현 원리**만 분석했습니다.

### 판단 기준 (01 문서)

- 주요 방문자: 어떤 립 색이 어울릴지 몰라 매번 실패하는 20대
- 가장 중요한 행동: 진단을 끝까지 마친 뒤 추천 상품 보기
- 보조 행동: 추천 립 구매, 전체 상품 둘러보기
- 전달할 인상: 친근하고 쉽다
- 피할 방향: 어려운 전문 용어, 구매를 서두르는 압박, 외모 평가 표현
- 주요 기기: 데스크톱

## 1. 레퍼런스 A · MAC Lip Shade Quiz (질문 화면)

- 위치: node-id=14-6 안 'image 1'
- 출처 표시: 화면 왼쪽 위에 'MAC LIP SHADE QUIZ'라고 적혀 있음

### 1-1. 직접 확인할 수 있는 특징

| 항목 | 확인한 내용 |
|---|---|
| 제목과 본문의 크기 관계 | 질문은 가운데 정렬 두 줄이고, 선택지 글자보다 한 단계 정도 큼. 크기 차이가 크지 않음. 질문과 선택지 모두 영문 대문자 |
| 여백 | 진행 막대와 질문 위쪽에 여백이 넉넉함. 선택지 4개는 좁은 간격으로 세로로 쌓여 있고, 선택지 폭이 화면 폭에 비해 좁음 |
| 컬러 | 배경은 흰색과 연한 회색, 선택지는 흰 바탕의 둥근 버튼. 화면 아래쪽에 여러 색의 립스틱 제품 사진이 한 줄로 놓여 있고, 화면의 색은 대부분 이 사진에서 나옴 |
| 그 밖의 구성 | 위쪽에 숫자 없는 짧은 진행 막대. 질문은 기분·분위기를 묻는 방식 |

### 1-2. 특징이 만드는 인상

- 화면 자체는 무채색이라 깔끔하고, **색은 제품에서만 나와서** 립 브랜드라는 점이 바로 보임
- 질문 하나에 선택지가 몇 개뿐이라 가볍고 빠르게 넘길 수 있는 느낌

### 1-3. 적용할 페이지·섹션과 이유

| 적용 위치 | 적용 방향 | 사이트 목적에 도움이 되는 이유 |
|---|---|---|
| **P02 진단 · S02-2 질문 화면** | 질문 카드 아래나 화면 아래쪽에 립 컬러 제품이 줄지어 있는 이미지 띠를 두고, 질문 화면 자체는 무채색으로 유지 | 진단 중에도 '결과로 립을 추천받는다'는 목적이 계속 보여서, 핵심 행동인 '진단을 끝까지 마치기'의 동기가 됨 |
| **P01 메인 · S01-2 소개 이미지** | 소개 이미지를 여러 립 컬러가 나란히 놓인 구성으로 채우는 방향 | 첫 화면에서 '다양한 립 색 중 나에게 맞는 것을 찾아준다'는 사이트 목적을 한눈에 보여줌 |
| **전체 화면의 컬러 원칙** | 배경과 버튼은 무채색에 가깝게 두고, 색은 제품 이미지와 컬러 칩에서만 나오게 함 | 립 색을 정확하게 보여줘야 추천 결과를 믿을 수 있음 |

### 1-4. 그대로 적용하지 않을 부분

| 부분 | 이유 |
|---|---|
| 질문과 선택지를 모두 대문자처럼 작고 촘촘하게 쓰는 방식 | 한글에는 맞지 않고, 작은 글자는 읽기 어려워 '쉽다'는 인상과 맞지 않음 |
| 폭이 좁고 작은 선택지 버튼 | 누를 수 있는 영역이 작음. 04 문서의 P02처럼 넓은 선택지가 더 쉬움 |
| 숫자 없는 진행 막대 | 립핏은 12문항(확인 필요)으로 질문이 많아서, 남은 양을 숫자로 보여주는 04 문서의 방식이 더 맞음 |
| 기분·분위기를 묻는 질문 문구 | 질문 내용은 아직 추후결정이고, 문구는 옮기지 않음 |

## 2. 레퍼런스 B · 4단계 응답 카드형 질문 화면

- 위치: node-id=14-6 안 'image 2'
- 출처 표시: 캡처에 브랜드나 사이트 이름이 없어 **출처를 확인하지 못함**

### 2-1. 직접 확인할 수 있는 특징

| 항목 | 확인한 내용 |
|---|---|
| 제목과 본문의 크기 관계 | 질문이 크고 굵은 흰 글자로 왼쪽 정렬 두 줄. 선택지 글자는 그보다 훨씬 작아서 크기 차이가 큼 |
| 여백 | 여백이 적고 촘촘함. 선택지 카드 4개가 2×2 격자로 화면을 꽉 채움 |
| 컬러 | 어두운 보라 계열 배경. 선택지 카드마다 보라·자홍·청록·황토 계열로 색이 다르고 테두리가 있음 |
| 그 밖의 구성 | 질문이 '제 피부는 ~해요' 같은 일상 문장이고, 답은 '전혀 아니에요 / 조금 그래요 / 대체로 그래요 / 완전히 그래요'의 4단계. 카드마다 번호(1~4)와 가운데 아이콘이 있음 |

### 2-2. 특징이 만드는 인상

- 어둡고 색이 강해서 몰입감 있고 게임처럼 느껴짐
- 답을 '정도'로 고르게 해서, 정답을 몰라도 부담 없이 답할 수 있는 느낌

### 2-3. 적용할 페이지·섹션과 이유

| 적용 위치 | 적용 방향 | 사이트 목적에 도움이 되는 이유 |
|---|---|---|
| **P02 진단 · S02-2 질문 화면** | 톤을 묻는 질문은 전문 용어 대신 '자연광에서 볼 때 내 피부는 ~해요'처럼 **일상 문장으로 쓰고**, 답은 **정도를 고르는 단계형**으로 받는 방식 | 방문자가 '웜톤·언더톤' 같은 용어를 몰라도 답할 수 있어서, 01 문서의 '어려운 전문 용어 피하기'와 '친근하고 쉽다'에 맞음. 답하기 쉬우면 끝까지 마칠 가능성도 높아짐 |
| **P02 진단 · S02-2 선택지** | 선택지마다 **번호를 붙이는 방식** | 데스크톱에서 숫자 키로 고르는 기능을 붙이기 쉽고, 몇 번째 답인지 말로 안내하기도 쉬움 |

### 2-4. 그대로 적용하지 않을 부분

| 부분 | 이유 |
|---|---|
| 어두운 배경과 선택지마다 다른 강한 색 | 화면 색이 강하면 립 색을 정확히 보기 어렵고, 답마다 색이 다르면 색 자체가 의미처럼 보여 답에 영향을 줄 수 있음 |
| 질문과 선택지의 큰 크기 차이, 작은 선택지 글자 | 선택지가 읽기 어려워짐. 어두운 배경 위 작은 글자는 대비 확인도 필요 |
| 의미 없는 장식 아이콘 | 답의 정도를 알려주지 못하는 아이콘은 쉬움에 도움이 되지 않음 |
| 2×2 격자 배치 | 정도를 고르는 답은 순서가 중요해서, 한 줄로 나란히 두거나 세로로 쌓는 편이 순서가 더 잘 읽힘 |

## 3. 레퍼런스 C · Lipstick Finder (단계형 질문 화면)

- 위치: node-id=14-6 안 'image 3'
- 출처 표시: 화면에 'Lipstick Finder'라고 적혀 있고 브랜드 이름은 보이지 않음. 앞선 조사에서 확인한 Clarins Lipstick Finder의 첫 질문 구성(원하는 효과 4가지)과 같아서 같은 서비스로 보임

### 3-1. 직접 확인할 수 있는 특징

| 항목 | 확인한 내용 |
|---|---|
| 제목과 본문의 크기 관계 | 맨 위 서비스 이름이 가장 크고, 한 단어만 색과 굵기로 강조됨. 질문은 그보다 작고, 질문 아래 안내 한 줄은 훨씬 작음. 선택지 카드 글자는 작은 대문자 |
| 여백 | 서비스 이름, 단계 표시, 질문, 안내 문구가 가깝게 묶여 있고, 그 아래 선택지 카드와는 여백이 넉넉함. 카드는 3열이고 4번째 카드가 다음 줄 가운데에 혼자 놓임 |
| 컬러 | 연한 분홍 계열의 흐릿한 배경, 흰 카드에 은은한 그림자, 아이콘과 카드 글자는 진한 분홍·빨강 계열 |
| 그 밖의 구성 | **번호 단계 표시(1-2-3) 끝에 립스틱 아이콘**이 있어 마지막이 결과임을 보여줌. 선택지는 선 아이콘과 짧은 문구가 있는 카드 |

### 3-2. 특징이 만드는 인상

- 부드럽고 고급스러우며, 단계가 보여서 **안내받으며 진행하는 느낌**
- 끝에 결과(립스틱)가 있다는 걸 미리 보여줘서 기대감이 생김

### 3-3. 적용할 페이지·섹션과 이유

| 적용 위치 | 적용 방향 | 사이트 목적에 도움이 되는 이유 |
|---|---|---|
| **P02 진단 · S02-1 진행 상태** | 진행 막대 끝에 **'결과'를 뜻하는 표시**를 두어, 마지막에 추천 립을 받는다는 걸 보여줌 | 진단을 끝까지 마쳐야 추천 상품을 볼 수 있다는 걸 계속 상기시켜, 핵심 행동의 이탈을 줄임 |
| **P02 진단 · S02-1 진행 상태** | 12문항(확인 필요)을 몇 개 묶음으로 나눠 단계 이름을 보여주는 방식 검토 | 질문이 많을 때 '지금 어디쯤인지'를 숫자보다 쉽게 알 수 있음 ▶ **변경 제안 2** |
| **P02 진단 · S02-2 질문 화면** | 질문 바로 아래에 **'하나를 골라 주세요' 같은 짧은 안내 한 줄** | 무엇을 해야 하는지 바로 알 수 있어 쉬움 |
| **P02 진단 · S02-2 선택지** | 선택지가 짧고 그림으로 나타낼 수 있는 질문(예: 원하는 마무리감)에만 **아이콘 + 짧은 문구 카드** 사용 | 글을 읽지 않고도 고를 수 있어 쉬움 |

### 3-4. 그대로 적용하지 않을 부분

| 부분 | 이유 |
|---|---|
| 연한 분홍 계열 배경 | 화면에 색이 깔리면 립 색이 다르게 보일 수 있음 (레퍼런스 A의 무채색 원칙과 충돌) |
| 카드 안의 작은 대문자 글자 | 한글에 맞지 않고 읽기 어려움 |
| 4번째 카드가 혼자 아랫줄에 놓이는 배치 | 선택지 수에 맞춰 한 줄 또는 고른 격자로 맞추는 편이 정돈돼 보임 |
| 서비스 이름의 한 단어 색 강조 | 문구·로고 표현을 옮기지 않음 |

## 4. 레퍼런스 D · Fenty Beauty 채팅 도움말

- 위치: node-id=14-6 안 'image 4'
- 출처 표시: 화면에 'Fenty Beauty'라고 적혀 있음

### 4-1. 직접 확인할 수 있는 특징

| 항목 | 확인한 내용 |
|---|---|
| 제목과 본문의 크기 관계 | 브랜드 이름이 작고 굵게 가운데에 있고, 본문은 모두 작은 글자. 크기 차이가 거의 없음 |
| 여백 | 위쪽에 이미지 띠, 그 아래 안내 문단과 질문 버튼 목록이 촘촘하게 이어짐. 입력창은 맨 아래에 떨어져 있음 |
| 컬러 | 흰 바탕에 연한 회청색 질문 버튼, 링크만 파란색 |
| 그 밖의 구성 | 맨 앞에 **정보 수집·이용 동의 안내 문단**(개인정보 처리방침, 이용약관 링크 포함). 그 아래 **추천 질문 버튼 5개**('내 파운데이션 셰이드 찾기' 등), 맨 아래 질문 입력창 |

### 4-2. 특징이 만드는 인상

- 차분하고 실용적인 고객센터 느낌
- 정보 이용 안내를 먼저 보여줘서 신뢰감은 있지만, 작은 글자가 많아 읽기 부담이 있음

### 4-3. 적용할 페이지·섹션과 이유

| 적용 위치 | 적용 방향 | 사이트 목적에 도움이 되는 이유 |
|---|---|---|
| **P01 메인 · S01-1** 또는 **P02 진단 시작 부분** | 진단에서 받은 답을 **어디에 쓰는지 짧게 알려주는 한 줄 안내** (예: 답변은 립 컬러 추천에만 쓰여요) | P02에서 연령대처럼 개인에 관한 질문을 받고 있어서, 쓰임을 먼저 알려주면 안심하고 끝까지 답할 수 있음 ▶ **변경 제안 4** |
| **진단 진입 방식 참고** | '셰이드 찾기'를 여러 도움말 중 맨 위에 두는 방식처럼, **진단을 가장 먼저 눈에 띄는 진입점**으로 두는 원칙 | 핵심 행동의 시작점을 가장 찾기 쉬운 곳에 둠. 04 문서의 B01-1(진한 테두리)과 같은 방향 |

### 4-4. 그대로 적용하지 않을 부분

| 부분 | 이유 |
|---|---|
| 채팅 기능 자체 | 01·04 문서에 없는 새 기능이라 이번에는 제안하지 않음 |
| 첫 화면에 긴 동의 문단을 작은 글자로 보여주는 방식 | 읽기 부담이 커서 '쉽다'와 맞지 않음. 필요하면 한 줄 안내와 자세히 보기로 나누는 편이 맞음 |
| 제목과 본문의 크기 차이가 거의 없는 구성 | 무엇이 중요한지 구분되지 않음 |

## 5. 레퍼런스 E · 카드형 질문 화면 (현재 P02 시안)

- 위치: node-id=14-6 안 'image 6'
- 출처 표시: 캡처에 출처가 없음. **04 문서의 P02 진단 화면에 들어간 이미지와 같은 화면**

### 5-1. 직접 확인할 수 있는 특징

### 7-2. 레퍼런스끼리 충돌하는 특징과 우선순위 제안

| 충돌 | 레퍼런스 | 우선 | 이유 (목적·구조 기준) |
|---|---|---|---|
| **배경 색**: 무채색 vs 색이 깔린 배경 | A, E(밝은 바탕) ↔ B(어두운 보라), C(연분홍), F(연라벤더) | **A 무채색** | 사이트의 핵심은 립 색 추천이라, 배경 색이 립 색을 다르게 보이게 하면 추천을 믿기 어려움 |
| **선택지 배치**: 세로 목록 vs 격자 카드 | A, E ↔ B, C | **E 세로 목록 기본**, 격자 카드는 짧고 그림으로 나타낼 수 있는 질문에만 | 질문이 많아(12문항, 확인 필요) 같은 틀이 반복되는 편이 쉽고, 세로 목록은 글이 긴 선택지도 잘 읽힘 |
| **진행 표시**: 숫자+막대 vs 숫자 없는 막대 vs 번호 단계 | E ↔ A ↔ C | **E 숫자+막대**, C의 '끝에 결과 표시'만 더함 | 질문이 많으면 번호 단계는 너무 길어지고, 숫자 없는 막대는 남은 양을 알기 어려움 |
| **제목과 본문의 크기 차이**: 뚜렷한 위계 vs 차이 없음 | F, C ↔ D | **F 뚜렷한 위계** (P01), E 정도의 중간 위계 (P02) | 첫 화면은 진단 시작 버튼이 가장 먼저 보여야 하고, 질문 화면은 질문과 선택지가 모두 잘 읽혀야 함 |
| **분위기**: 몰입형·게임형 vs 차분한 설문형 | B ↔ E | **E 차분한 설문형** | '친근하고 쉽다'는 인상에 맞고, 강한 연출은 질문이 많을 때 피로해짐 |
