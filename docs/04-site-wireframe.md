## 2. 표기 기준

| 표기 | 의미 |
|---|---|
| X 상자 | 이미지 |
| 대각선이 그어진 상자 | 이미지 자리 (상품 카드 안) |

## 3. 배치

- 맨 위: P01 메인
- 둘째 줄: P02 진단 5장을 가로로 나란히 (진단 단계별 화면 자리)
- 셋째 줄: P03 진단 결과
- 넷째 줄: P04 상품 상세, 그 오른쪽에 구매완료 팝업창

## 7. 확인이 필요한 사항

Figma에 그려졌지만 기획 문서와 맞춰봐야 하는 내용입니다. 확정 사항으로 쓰지 않았습니다.

1. **질문 수**: P02에 '1 / 12'로 표기됨. 02 문서에서는 질문 수가 추후결정이라, 12문항으로 확정할지 확인 필요
2. **P02 화면 5장**: 5장 모두 같은 내용(1/12, 연령대 질문). 질문별 화면으로 채울 예정인지, 12문항 중 일부만 그릴지 확인 필요
3. **결과로 넘어가는 버튼**: 마지막 질문에서 '다음'이 결과 화면으로 가는지, 별도의 '결과 보기' 버튼을 둘지
4. **추천 상품 수와 넘김 방식**: 카드 6개를 보여주고 ‹ › 로 넘기는 방식인지. 02 문서의 '추천 컬러 수'(추후결정)와 함께 정해야 함
5. **찜·저장 기능과 회원가입**: P01에 '회원가입 없이 바로 확인'이라고 적혀 있는데, P03의 찜·저장하기는 보통 회원 기능이 필요함. 02 문서의 '결과 저장·공유, 회원 기능 필요 여부'(추후결정)와 함께 정해야 함
6. **EWG 그린·안전 인증 배지**: 실제 인증 정보가 필요한 표시라, 가상 상품에서 사용할지 확인 필요
7. **구매 방식**: P05 구매 화면 없이 구매완료 팝업으로 끝나는 방식인지. P04 안내 문구('구매 화면의 구성 예시로 연결')와 맞지 않음
8. **전체 상품 둘러보기 경로**: '더보기'가 빠지고 상품 목록(P06) 화면도 없어, 01 문서의 보조 행동 '전체 상품 둘러보기'로 가는 길이 없음
9. **메뉴 축소**: MN-02 진단하기, MN-03 상품 보기를 빼고 로고만 둘지 확정 필요
10. **P02 '다음' 버튼 색**: 연한 핑크 위 흰 글자는 대비가 낮아 보임. 선택 전 비활성 상태라면 문제없지만, 활성 상태라면 진한 색으로 바꿔야 함
11. **Figma 레이어 이름**: P03 넘김 버튼(‹ ›)과 공유하기·저장하기 레이어 이름이 'MN-01 로고', P04 '공유하기' 버튼 레이어 이름이 'B04-1 구매하기'로 되어 있어 정리 필요

## 8. 추후결정 항목 (02 문서 기준)

- 구매 방식 (B04-1 목적지, P05 화면 여부)
- 진단 질문 수와 질문 내용, 선택지 수
- 결과로 나눌 톤 종류 (Figma 추천 영역 프레임 이름 '톤 종류 미정')
- 결과 화면에 보여줄 추천 컬러 수 (Figma에는 예시로 6개)
- 상품 수와 상품 상세에 들어갈 정보 항목 (P04 점선 상자: 가격·용량·제형·전성분·배송 조건 등)
- 결과 저장·공유, 회원 기능 필요 여부
