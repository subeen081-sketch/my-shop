# 립핏 디자인 시스템

립핏(LipFit)은 몇 가지 질문으로 퍼스널컬러를 진단하고, 내 톤에 맞는 립 컬러를 추천해 주는 가상 립 브랜드입니다. 이 시스템은 디자인 캔버스 '립핏 시각 디자인'(P01 메인, P02 진단, P03 진단 결과, P04 상품 상세, 구매완료 팝업)에 실제로 쓰인 값만 모았습니다. 기준 화면은 데스크톱 1440px이고, 아직 밝은 테마 한 가지뿐입니다.

## 디자인 원칙

- **화사하되 립 색을 가리지 않는다.** 바탕은 아주 옅은 블러시에서 흰색으로 흐르고, 진한 색(`rose-500`)은 작은 면적에만 씁니다. 화면 전체에 진한 색을 깔거나 선택지마다 다른 색을 쓰지 않습니다.
- **해야 할 일이 먼저 보인다.** 화면마다 핵심 행동은 하나이고, 그 버튼만 로즈로 채웁니다(메인 '진단 시작하기', 진단 '다음', 상세 '구매하기').
- **차분한 설문.** 진단 화면은 폭을 좁히고(`container-narrow`), 장식 없이 질문과 넓은 선택지만 둡니다.
- **넓은 여백.** 묶을 것은 가깝게(12~40px), 섹션 사이는 넓게(96px) 둡니다.

## 말투

옆에서 차근차근 알려 주는 친구처럼, 짧고 쉬운 해요체로 씁니다. 전문 용어, 구매를 서두르는 말, 외모를 평가하는 말은 쓰지 않습니다.

- 예: "정답은 없어요. 평소 내 모습에 가까운 쪽을 골라 주세요."
- 예: "실제로 판매하지 않는 가상 상품이에요"
- 문서에 없는 가격·후기·기능은 지어내지 않고 `[가격]`처럼 대괄호 자리로 둡니다.

## 컬러

| 역할 | 토큰 | 규칙 |
| --- | --- | --- |
| 바탕 | `page-top` → `page-mid` → `surface` | 모든 화면 바탕은 `linear-gradient(180deg, page-top 0%, page-mid 38%, surface 100%)`. 헤더는 투명 + `line-header` 아래선 |
| 면 | `surface` + `shadow-card` | 카드·질문 카드는 흰 면 + `line-100` 테두리 + 옅은 그림자로 띄움 |
| 블러시 | `blush-100`, `blush-200` | 배너, 안내 배지, 번호 원 같은 작은 면 |
| 글자 | `ink`, `ink-muted`, `ink-subtle` | 제목·본문은 `ink`, 설명은 `ink-muted`, 작은 안내는 `ink-subtle` |
| 포인트 | `rose-500` (호버 `rose-600`) | 버튼 채움, 선택된 선택지, 진행 막대, New 배지, 완료 표시, 로고에만 |
| 이미지 자리 | `image-slot` | 이미지가 들어갈 자리는 모두 밝은 회색. 핑크를 쓰지 않아 실제 이미지가 오면 바로 구분됨 |
| 립 컬러 | `lip-petal` … `lip-plum` | 장식 전용(메인 히어로 칩과 칩 띠). 결과 화면에는 쓰지 않음: 추천 색처럼 보일 수 있어서 |

## 타이포그래피

글꼴은 IBM Plex Sans KR(Google Fonts) 한 가지입니다. 한글은 단어 단위로 줄을 바꿉니다(`word-break: keep-all`). 작고 촘촘한 대문자식 글자는 쓰지 않습니다.

- 메인: `display-hero`(52/700) > `body-lead`(20/400) > `button-l`(18/600) > `caption`(15/500). 뚜렷한 위계.
- 진단: `title-question`(28/600) > `choice`(18/500) > `caption`(15/500). 중간 위계.
- 결과·상세: `display-page`(40/700) > `body-lead` 또는 `title-product`(32/700).

## 레이아웃

- 내용 폭은 `container`(1200px), 진단만 `container-narrow`(768px). 좌우 여백 `space-6`.
- 헤더 `header-height`(72px), 로고만 있음.
- 헤더 아래 첫 내용까지 `space-24`(96px), 큰 섹션 사이 `space-24`, 화면 맨 아래 `space-30`(120px).
- 메인은 한 열 가운데 정렬. 제목·설명·버튼·진행 단계를 한 묶음으로 두고(20·40·28px), 칩 띠와 이미지는 `space-16`(64px) 띄움.
- 추천 카드는 3열, 사이 `space-6`. 양옆에 넘김 버튼.

## 반복 요소

- 버튼은 모두 알약형(`radius-pill`). 핵심은 `rose-500` 채움 + 흰 글자, 보조는 흰 바탕 + `line-200` 테두리, 되돌아가기(이전)는 밑줄 글자형, 비활성은 `line-100` 바탕 + `ink-subtle` 글자.
- 카드·이미지·다이얼로그 모서리 `radius-lg`(20px), 선택지와 카드 안 이미지 `radius-md`(14px).
- 선택지는 폭 전체를 쓰는 64px 상자. 선택되면 `rose-500` 채움 + 흰 글자 + 오른쪽 흰 원 안 로즈 체크.

## 움직임

| 위치 | 움직임 |
| --- | --- |
| 버튼 | 호버 시 주요 버튼은 `rose-600`, 화살표 4px 이동. 누르면 0.98배 |
| 보조 버튼·선택지 | 호버 시 `blush-100` 바탕, `line-300` 테두리 |
| 추천 카드 | 호버 시 2px 떠오르고 `shadow-card-hover` |
| 메인 히어로 | 제목 → 설명 → 버튼 → 진행 단계가 0.08초 간격으로 아래에서 위로 나타남(0.45초) |
| 컬러칩 | 호버 시 1.3배 커지고 4px 떠오름, `shadow-chip` |
| 진단 | 진행 막대가 0.3초에 걸쳐 늘어남, 질문 카드는 옆에서 밀려 들어옴 |
| 결과 이미지 | 커서 쪽이 빳빳한 판처럼 최대 4도 기울며 6px 눌림 |
| 다이얼로그 | `overlay`가 나타나고 다이얼로그가 아래에서 올라옴 |

동작 줄이기 설정(`prefers-reduced-motion`)을 켠 방문자에게는 모든 움직임을 끕니다. 키보드 초점은 2px `ink` 외곽선(간격 3px)으로 보여 줍니다.

## 로고

임시 로고입니다(최종은 에셋 단계에서 확정). `rose-500` 26px 둥근 사각형(`radius-sm`) 안에 흰 곡선, 그 옆에 'LipFit' 워드마크(`logo`)와 '립핏'(15px/500, `ink-muted`). 로고 파일은 아직 없어서 Header 컴포넌트 미리보기에 코드로만 그려 두었습니다.

## 아직 정하지 않은 것

어두운 테마, 모바일 배치, 최종 로고와 이미지, 구매완료 팝업의 문구와 닫기 방식, 추천 카드 수와 넘김 방식, 찜·공유·저장 동작.
