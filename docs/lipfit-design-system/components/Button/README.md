# Button

알약형 버튼으로, 화면마다 핵심 행동 하나만 주요(로즈 채움)로 둡니다.

- **주요**: `rose-500` 채움, `on-rose` 글자, 높이 `control-l`(60px) 또는 `control-m`(52px), `button-l`/`button-m`. 호버 `rose-600`, 화살표 4px 이동.
- **보조**: `surface` 바탕 + `line-200` 테두리, `ink` 글자. 호버 `blush-100` 바탕 + `line-300` 테두리.
- **글자형**: 되돌아가기(이전) 전용. 밑줄, 호버 시 `rose-500` 글자.
- **비활성**: `line-100` 바탕 + `ink-subtle` 글자. 진단에서 선택지를 고르기 전 '다음'.
- 아이콘이 있으면 글자 뒤(화살표) 또는 앞(공유·저장), 사이 `space-2`.
