# ColorChip

립 색을 둥근 칩으로 보여 주는 장식 요소입니다(메인 히어로 양옆과 히어로 아래 칩 띠).

- 칩 띠: 20px 원 8개, 사이 `space-3`, 연한 쪽에서 진한 쪽으로 `lip-petal` → `lip-plum`.
- 히어로 장식: 24~56px 원, 알약형 칩, 립스틱 모양(`lip-red`·`lip-coral` 몸체 + `lipstick-case` 케이스)을 비스듬히 배치.
- 호버 시 1.3배(장식은 1.15배) 커지고 위로 떠오르며 `shadow-chip`.
- 장식이므로 화면 읽기 프로그램에서 숨깁니다(`aria-hidden`). 결과 화면에는 쓰지 않습니다.
