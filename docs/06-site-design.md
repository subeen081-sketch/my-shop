## 2. 디자인 원칙

| 원칙 | 화면에서 지키는 방법 |
|---|---|
| 화사하되 립 색을 가리지 않는다 | 바탕은 아주 옅은 블러시에서 흰색으로 흐름. 진한 로즈는 작은 면적에만 씀. 화면 전체에 진한 색을 깔거나 선택지마다 다른 색을 쓰지 않음 |
| 해야 할 일이 먼저 보인다 | 화면마다 핵심 행동 하나만 로즈로 채움 (P01 '진단 시작하기', P02 '다음'·'결과 보기', P04 '구매하기') |
| 차분한 설문 | P02는 내용 폭을 768px로 좁히고, 장식 없이 질문과 넓은 선택지만 둠 |
| 넓은 여백 | 묶을 것은 가깝게(12~40px), 섹션 사이는 넓게(96px) |

## 3. 말투

| 항목 | 내용 |
|---|---|
| 한 줄 설명 | 옆에서 차근차근 알려 주는 친구처럼, 짧고 쉬운 해요체 |
| 피할 표현 | 어려운 전문 용어, 구매를 서두르는 압박, 외모 평가 (01 문서) |
| 예시 문장 | "정답은 없어요. 평소 내 모습에 가까운 쪽을 골라 주세요." / "실제로 판매하지 않는 가상 상품이에요" |
| 정해지지 않은 문구 | 지어내지 않고 `[가격]`, `[배너 문구]`처럼 대괄호 자리로 둠 |

## 4. 컬러

### 4-1. 사용 규칙

| 역할 | 토큰 | 규칙 |
|---|---|---|
| 페이지 바탕 | `page-top` → `page-mid` → `surface` | 모든 화면 바탕은 위에서 아래로 `linear-gradient(180deg, #FFEEF3 0%, #FFF7F9 38%, #FFFFFF 100%)`. 헤더는 투명 + `line-header` 아래선 |
| 면 | `surface` | 카드·질문 카드·다이얼로그는 흰 면 + `line-100` 테두리 + `shadow-card` |
| 블러시 | `blush-100`, `blush-200` | 카드 헤더 배너, 가상 상품 안내 배지, 진행 단계 번호 원처럼 작은 면에만 |
| 글자 | `ink`, `ink-muted`, `ink-subtle` | 제목·본문 `ink`, 설명 `ink-muted`, 작은 안내·진행 숫자 `ink-subtle` |
| 포인트 | `rose-500` (호버 `rose-600`) | 버튼 채움, 선택된 선택지, 진행 막대, New 배지, 구매완료 표시, 로고에만 |
| 이미지 자리 | `image-slot` | 이미지가 들어갈 자리는 모두 밝은 회색. 실제 이미지가 들어오면 사라짐 |
| 립 컬러 | `lip-petal` ~ `lip-plum` | 장식 전용(P01 히어로 칩과 칩 띠). P03 결과 화면에는 쓰지 않음(추천 색처럼 보일 수 있어서) |

## 10. 접근성 기준

- 글자는 바탕과 4.5:1 이상 (4-2 표의 대비 참고). 로즈 버튼의 흰 글자는 약 4.9:1
- 호버로 바탕을 바꿀 때는 더 진한 색(`rose-600`)으로 바꿔 글자 대비를 유지
- `line-300`(약 1.9:1)은 장식에만 쓰고, 정보를 담는 아이콘에는 쓰지 않음
- 선택지는 `role="radiogroup"`·`role="radio"`·`aria-checked`, 진행 막대는 `role="progressbar"`·`aria-valuenow`, 팝업은 `role="dialog"`·`aria-modal`
- 아이콘만 있는 버튼(찜, ‹ ›)에는 `aria-label`
- 장식(컬러칩, 립스틱, 진행 단계 화살표)은 `aria-hidden`
- 누르는 영역은 44px 이상 (찜 버튼 44px, 넘김 버튼 48px, 선택지 64px)
