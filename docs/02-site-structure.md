# 립핏(LipFit) 페이지 구성

기준 문서: 01-site-purpose.md

## 1. 확정한 내용

### 1-1. 페이지 구성

| 페이지 | 묶은 기능 | 연결된 목적 |
|---|---|---|
| 메인 | 사이트 소개, 진단 안내, 진단 시작 | 핵심 행동의 출발점 |
| 진단 | 질문 | 핵심 행동 (진단 완료) |
| 진단 결과 | 결과, 추천 상품 | 핵심 행동 (추천 상품 보기) |
| 상품 목록 | 전체 상품 둘러보기 | 보조 행동 |
| 상품 상세 | 상품 정보 | 추천·목록에서 구매로 이어지는 연결 |
| 구매 | 구매 기능 | 보조 행동 |

### 1-2. 방문자 흐름

| 방문자 행동 | 필요한 정보·기능 | 배치할 페이지 / 섹션 | 다음 행동 |
|---|---|---|---|
| 사이트에 처음 들어옴 | 립핏이 어떤 곳인지 한 문장 설명 | 메인 > 첫 화면 소개 영역 | 진단 시작 |
| 진단을 할지 망설임 | 진단이 쉽고 부담 없다는 안내 (진단 방식 설명) | 메인 > 진단 안내 영역 | 진단 시작 |
| 진단 시작 | 진단 시작 버튼 | 메인 | 질문에 답하기 |
| 질문에 답함 | 퍼스널컬러 진단 질문, 진행 상태 표시 | 진단 > 질문 화면 | 결과 확인 |
| 진단 결과 확인 | 내 톤 결과, 결과에 대한 쉬운 설명 | 진단 결과 > 결과 영역 | 추천 상품 보기 |
| 추천 상품 보기 (핵심 행동) | 내 톤에 맞는 립 컬러 추천 | 진단 결과 > 추천 영역 | 상품 상세 보기 또는 구매 |
| 추천 상품 자세히 보기 | 상품 정보 | 상품 상세 | 구매 |
| 추천 립 구매 (보조 행동) | 구매 기능 | 구매 | 구매 완료 |
| 전체 상품 둘러보기 (보조 행동) | 전체 립 상품 목록 | 상품 목록 | 상품 상세 보기 또는 진단 시작 |

### 1-3. 확정한 선택

- 진단 결과는 진단(질문) 페이지와 나누어 **별도 페이지**로 구성

### 1-4. 모든 페이지에 적용할 기준 (01-site-purpose.md에서 확정)

- 데스크톱 기준으로 구성
- 친근하고 쉬운 인상
- 어려운 전문 용어, 구매를 서두르는 압박, 외모 평가 표현은 피함

## 2. 추후 결정

### 2-1. 선택이 필요한 부분

**구매를 어떤 방식으로 처리할지**

| 대안 | 이유 |
|---|---|
| A. 장바구니·주문 페이지를 직접 구성 | 브랜드 사이트 안에서 구매까지 완결됨. 대신 기획 범위가 커짐 |
| B. 상품 상세의 구매 버튼까지만 구성하고 이후 과정은 생략 | 실습 범위를 진단과 추천에 집중할 수 있음 |

### 2-2. 정하지 않은 세부 사항

- 진단 질문 수와 질문 내용
- 결과로 나눌 톤 종류
- 결과 화면에 보여줄 추천 컬러 수
- 상품 수와 상품 상세에 들어갈 정보 항목
- 진단 시작 버튼을 메인 외 다른 페이지에도 둘지 여부
- 결과 저장·공유, 회원 기능 필요 여부
