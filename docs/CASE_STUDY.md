## 2. 기획 의도

| 항목 | 내용 |
| --- | --- |
| 배경 | 주요 방문자는 어떤 립 색이 어울릴지 몰라 매번 실패하는 20대다. (초안) 립 색은 사진만 보고 고르기 어렵고, 내 톤에 맞는지 판단할 기준이 없으면 같은 실패가 반복된다. 기존 사이트에서 직접 느낀 아쉬운 점 ✏️ 직접 채우기 |
| 목표 | 방문자가 자기 톤을 알고, 그 톤에 맞는 립 색을 추천받게 한다. 진단은 차분한 설문처럼 느껴지고, 말투는 옆에서 차근차근 알려 주는 친구처럼 짧고 쉬운 해요체로 한다 |
| 타깃 사용자 한 줄 | 어떤 립 색이 어울릴지 몰라 매번 실패하는 20대 |
| 배경과 목표의 연결 | (초안) "어울리는 색을 모른다"는 문제를 "몇 가지 질문으로 내 톤을 알려 주고, 그 톤의 립을 바로 보여 준다"로 푼다. 그래서 가장 중요한 행동을 "진단을 끝까지 마친 뒤 추천 상품 보기"로 정했다 |

## 3. 핵심 가설

| 항목 | 내용 |
| --- | --- |
| 가설 설정 배경 한 줄 | (초안) 사이트의 가장 중요한 행동이 "진단을 끝까지 마친 뒤 추천 상품 보기"이므로, 12문항 진단을 중간에 그만두지 않게 하는 것이 핵심이다. 레퍼런스(카드형 질문 화면, Fenty Beauty 진단 진입점)를 근거로 삼았다 |
| IF | (초안) 진단을 한 화면에 질문 하나씩 보여 주는 카드로 만들고, 위쪽에 '1 / 12'와 진행률·진행 막대를 보여 주며, 선택지를 골라야 '다음'이 켜지게 하면 |
| THEN | (초안) 방문자는 12번째 문항까지 답하고 '결과 보기'를 눌러 결과 화면의 추천 립 카드까지 이동한다 |
| 검증 방향 | (초안) 처음 보는 사람이 TC-26(데스크톱)·TC-27(휴대폰) 핵심 흐름 케이스를 그대로 따라 해서, 막히는 단계 없이 결과 화면 추천 카드까지 가는지 본다 |

## 5. 인터랙션 설계

### 사이트 구성 한눈에 보기

| 순서 | 화면 | 하는 일 | 핵심 인터랙션 |
| --- | --- | --- | --- |
| 1 | P01 메인 | 진단 시작 | '진단 시작하기', 진행 단계 미리보기(질문에 답하기 › 내 톤 확인 › 추천 립 보기) |
| 2 | P02 진단 | 12문항에 하나씩 답하기 | **인터랙션 1** 카드형 질문 + 진행 상태 |
| 3 | P03 진단 결과 | 내 톤(웜·쿨·뉴트럴) 확인, 추천 립 9개 보기 | **인터랙션 2** 결과 카드 뒤집기, **인터랙션 3** 추천 카드 슬라이드 |
| 4 | P04 상품 상세 | 누른 상품 확인, 구매하기 | 구매하기 → PU-01 구매완료 팝업 |

모든 화면 위에는 로고만 있는 공통 헤더(MN-01)가 있고, 로고를 누르면 메인으로 돌아간다. ✏️ 화면 흐름도 이미지 넣기

### 인터랙션 1. 카드형 진단과 진행 상태 (P02)

| 항목 | 내용 |
| --- | --- |
| 무엇을 | 흰 카드에 질문 하나와 넓은 선택지를 세로로 보여 준다. 위쪽 왼쪽에 '현재 / 12', 오른쪽에 진행률(%), 아래 진행 막대가 있고 문항을 넘기면 막대가 0.3초에 걸쳐 늘어난다. 선택 전에는 '다음'이 비활성이고, 고르면 선택지가 로즈색으로 채워지며 '다음'이 켜진다. '이전'으로 돌아가도 고른 답이 남아 있고, 12번째 문항에서는 '다음' 자리에 '결과 보기'가 나온다 |
| 왜 | (초안) 12문항은 짧지 않다. 지금 어디쯤인지와 남은 양을 계속 보여 주고, 한 번에 하나만 묻게 해서 끝까지 답하게 한다(3장 가설의 IF) |

| 검증 근거 | 핵심 흐름(TC-26 데스크톱, TC-27 휴대폰)과 톤 판정(TC-09~TC-11)을 포함한 테스트 케이스 27개가 모두 통과로 기록되어 있다(실패 0). 진단을 시작해 12문항을 마치고 결과 화면의 추천 립까지 가는 흐름이 막히지 않고 동작한다는 근거다. 누가 몇 명 테스트했는지 ✏️ 직접 채우기 |
| 한계 | 테스트 결과는 27개 중 27개 통과(실패 0)로 기록되어 있지만, 테스트한 사람과 인원은 기록되지 않았다. 테스트는 기대 결과대로 동작하는지(기능)를 확인한 것이어서, 처음 보는 방문자가 스스로 끝까지 간다는 THEN을 확인한 것과는 다르다. 실제 방문자 반응은 아직 확인하지 않았다 |
| 마무리 한 문장 | (초안) 진단을 끝까지 마치게 하는 흐름을 만들고 그 흐름을 테스트로 확인할 준비까지 했다. 다음 단계는 실제 사용자 테스트로 THEN을 확인하는 것이다 |
