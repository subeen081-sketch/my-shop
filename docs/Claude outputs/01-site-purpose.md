# 립핏(LipFit) 사이트 목적 정의

## 1. 사이트 목적 한 문장

립핏은 몇 가지 질문으로 나의 퍼스널컬러를 진단하고, 내 톤에 꼭 맞는 립 컬러를 추천해 주는 립 브랜드입니다.

- 상태: 확정

## 2. 주요 방문자와 방문자의 필요

| 구분 | 내용 | 상태 |
|---|---|---|
| 주요 방문자 | 어떤 립 색이 어울릴지 몰라 매번 실패하는 20대 | 확정 |
| 방문자의 필요 | 내 톤을 알고, 그 톤과 맞는 립 색을 추천받는 것 | 확정 |
| 주요 기기 | 데스크톱 기준으로 진행 | 확정 |

## 3. 가장 중요한 행동과 보조적인 행동

| 구분 | 내용 | 상태 |
|---|---|---|
| 가장 중요한 행동 | 진단을 끝까지 마친 뒤 추천 상품 보기 | 확정 |
| 보조적인 행동 1 | 추천 립 구매 | 확정 |
| 보조적인 행동 2 | 전체 상품 둘러보기 | 확정 |

## 4. 전달하고 싶은 인상과 피하고 싶은 방향

| 구분 | 내용 | 상태 |
|---|---|---|
| 전달하고 싶은 인상 | 친근하고 쉽다 | 확정 |
| 피하고 싶은 방향 1 | 어려운 전문 용어 | 확정 |
| 피하고 싶은 방향 2 | 구매를 서두르는 압박 | 확정 |
| 피하고 싶은 방향 3 | 외모 평가 표현 | 확정 |

## 5. 기획을 위한 가정

'추측해서 정해줘'로 답한 항목이 없어, 현재 가정으로 둔 내용은 없습니다.
