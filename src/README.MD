## 4. 주요 기능

- **한 화면에서 차례로 넘기는 12문항 진단**: 질문 카드 하나에 문항을 하나씩 보여 주고, 위쪽 진행 숫자·진행률·막대로 지금 어디쯤인지 알려 줘요. 선택지를 골라야 '다음'이 켜지고, '이전'으로 돌아가도 고른 답이 그대로 남아요.
- **진단 결과와 추천 립을 한 페이지에**: 결과 이미지 카드를 누르면 뒤집혀서 내 톤 요약이 나오고, 그 아래에 추천 립 9개가 카드로 이어져요. ‹ › 버튼으로 넘겨 보고, 카드를 누르면 상품 상세로 바로 가요.
- **상품 상세와 가상 구매 흐름**: 가격·제형·추천 톤을 한눈에 보여 주고, '구매하기'를 누르면 구매완료 팝업이 떠요. 실습용 가상 상품이라 실제 결제와 배송은 없다는 안내를 화면에 함께 적었어요.

## 5. 트러블슈팅

### 이슈 1: GitHub Pages 하위 주소(/my-shop/)에서 페이지 이동이 맞지 않음

- **문제**: 사이트가 `https://아이디.github.io/my-shop/` 아래에 올라가서, `/diagnosis`처럼 루트 기준으로 만든 주소와 이미지·스크립트 경로가 맞지 않고, `/my-shop/result`에서 새로고침하면 404가 나는 구조였음
- **원인**: Vite와 React Router가 모두 사이트를 도메인 루트(`/`)에 둔다고 가정하고 있었고, GitHub Pages는 `/my-shop/result` 같은 주소에 해당하는 실제 파일이 없으면 404 페이지를 돌려줌
- **해결**: `vite.config.js`에 `base: '/my-shop/'`을 넣고, `BrowserRouter`에 `basename={import.meta.env.BASE_URL}`을 줌. 배포 workflow에서 빌드 후 `index.html`을 `404.html`로 복사해 어느 주소로 들어와도 앱이 뜨게 함

### 이슈 2: 작은 휴대폰에서 메인 제목과 진행 단계 글자가 어색하게 꺾임

- **문제**: 폭 320px에서 제목이 '나에게 어울리는 립 / 컬러, / 립핏에서 찾아보세요'처럼 '컬러,'만 따로 떨어지고, 375px 이하에서는 진행 단계 이름이 '질문에 / 답하기'처럼 두 줄로 꺾임
- **원인**: 30px 제목 첫 줄이 내용 폭 288px보다 넓었고, 진행 단계 세 개(번호 원 + 이름)를 한 줄에 나란히 두면 화면 폭을 넘어서 각 이름이 줄어들며 꺾였음
- **해결**: 359px 이하에서 제목을 28px로 줄이고, 모바일에서는 번호 원을 단계 이름 위에 두고 이름을 한 줄로 고정함. 320·375·768px에서 가로로 넘치는 요소가 없는지 스크립트로 확인함

### 이슈 3: 흰 바탕 로고 이미지가 분홍 그라데이션 헤더 위에서 사각형으로 보임

- **문제**: 로고 파일(`logo.jpg`)을 그대로 넣으면 로고 마크 주변에 흰 사각형이 드러남
- **원인**: 로고 이미지가 가로로 긴 흰 바탕 JPG라 투명한 부분이 없음
- **해결**: 이미지 파일은 그대로 두고, 26px 틀 안에서 로즈 사각형 부분만 보이도록 CSS로 위치를 맞춰 잘라 보여 줌(`overflow: hidden` + `border-radius`)

### 이슈 4: 문서 파일이 저장되지 않음 (EPERM 오류)

- **문제**: 진행 상황을 적어 두는 `PROJECT_CONTEXT.md`를 고치려 하자 `EPERM: operation not permitted` 오류가 나며 저장이 막힘
- **원인**: 같은 파일을 다른 프로그램(Word)에서 열어 두어 파일이 잠겨 있었음. 폴더의 `~$OJECT_CONTEXT.md` 잠금 파일로 확인함
- **해결**: 열어 둔 프로그램에서 파일을 닫은 뒤 다시 저장함
