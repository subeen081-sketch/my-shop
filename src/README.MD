## 3. 사용 기술

- **React, Vite**: 질문 선택지·결과 카드·헤더처럼 반복되는 화면을 컴포넌트로 나눠 재사용하고, Vite로 빠르게 개발 화면을 확인하며 GitHub Pages용 정적 파일로 빌드하기 위해 사용
- **GitHub Pages**: 무료 배포
- **Figma**: 와이어프레임 작성
- **Claude**: 디자인 및 바이브코딩 (화면 구현)

## 4. 주요 기능

- **한 화면에서 차례로 넘기는 12문항 진단**: 질문 카드 하나에 문항을 하나씩 보여 주고, 위쪽 진행 숫자·진행률·막대로 지금 어디쯤인지 알려 줘요. 선택지를 골라야 '다음'이 켜지고, '이전'으로 돌아가도 고른 답이 그대로 남아요.
- **진단 결과와 추천 립을 한 페이지에**: 결과 이미지 카드를 누르면 뒤집혀서 내 톤 요약이 나오고, 그 아래에 추천 립 9개가 카드로 이어져요. ‹ › 버튼으로 넘겨 보고, 카드를 누르면 상품 상세로 바로 가요.
- **상품 상세와 가상 구매 흐름**: 가격·제형·추천 톤을 한눈에 보여 주고, '구매하기'를 누르면 구매완료 팝업이 떠요. 실습용 가상 상품이라 실제 결제와 배송은 없다는 안내를 화면에 함께 적었어요.
